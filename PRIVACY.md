# Privacy Policy / Datenschutzerklärung

Effective date / Gültig ab: 2026-08-04

## English

Local Gear Advisor is a local-only Windows companion for World of Warcraft.

### Data processed locally

The app processes data that the user explicitly provides, including SimulationCraft exports, character and equipment information, selected local file paths, SimulationCraft reports, and generated Local Gear Advisor results. This data is processed and stored only on the user's Windows device under `%LOCALAPPDATA%\LocalGearAdvisor`, unless the user explicitly chooses another supported local path.

### No collection or transmission

The app does not collect, transmit, sell, share, or monetize personal data. It has no telemetry, advertising, analytics, account system, cloud backend, or Raidbots integration. Character, inventory, simulation, and result data is not sent to the developer, Microsoft, Wago, or any simulation service.

SimulationCraft runs as a separate executable selected by the user and performs the simulation locally. The app does not bundle or download `simc.exe`.

The "Download SimulationCraft" button opens the fixed public page `https://www.simulationcraft.org/download.html` in the user's default web browser after an explicit click. The app itself does not download or execute content from that site. The browser and website have their own privacy policies.

The app accesses the Windows clipboard only after an explicit user action to copy generated import text. It reads user-selected text or files only after an explicit paste, file selection, or load action.

### World of Warcraft files

Routine result transfer uses an integrity-checked copy/paste format. Optional file installation is disabled by default and is performed only after an explicit user action and the app's fail-closed World of Warcraft process checks. The app never modifies World of Warcraft SavedVariables externally.

### Deletion

Uninstalling the Microsoft Store package removes the packaged app. Locally generated user data may remain under `%LOCALAPPDATA%\LocalGearAdvisor` so that an uninstall or update does not silently destroy simulation results. Users can delete that directory manually when they no longer need the data. World of Warcraft addon data remains under the user's World of Warcraft installation until removed by the user.

### Contact

Privacy questions can be submitted through the project's public issue tracker:
https://github.com/Madchristian/local-gear-advisor/issues

## Deutsch

Local Gear Advisor ist ein ausschließlich lokal arbeitender Windows-Helfer für World of Warcraft.

### Lokal verarbeitete Daten

Die Anwendung verarbeitet Daten, die der Nutzer ausdrücklich bereitstellt. Dazu gehören SimulationCraft-Exporte, Charakter- und Ausrüstungsinformationen, ausgewählte lokale Dateipfade, SimulationCraft-Berichte und erzeugte Local-Gear-Advisor-Ergebnisse. Diese Daten werden ausschließlich auf dem Windows-Gerät des Nutzers unter `%LOCALAPPDATA%\LocalGearAdvisor` verarbeitet und gespeichert, sofern der Nutzer nicht ausdrücklich einen anderen unterstützten lokalen Pfad auswählt.

### Keine Erfassung oder Übertragung

Die Anwendung erfasst, überträgt, verkauft, teilt oder monetarisiert keine personenbezogenen Daten. Sie enthält keine Telemetrie, Werbung, Analysefunktion, Benutzerkonten, Cloud-Anbindung oder Raidbots-Integration. Charakter-, Inventar-, Simulations- und Ergebnisdaten werden weder an den Entwickler noch an Microsoft, Wago oder einen Simulationsdienst gesendet.

SimulationCraft läuft als separat vom Nutzer ausgewählte ausführbare Datei und führt die Simulation lokal aus. Die Anwendung liefert `simc.exe` weder mit noch lädt sie die Datei herunter.

Die Schaltfläche „SimulationCraft herunterladen“ öffnet nach einem ausdrücklichen Klick ausschließlich die feste öffentliche Seite `https://www.simulationcraft.org/download.html` im Standardbrowser. Die Anwendung selbst lädt keine Inhalte von dieser Seite herunter und führt sie nicht aus. Für Browser und Website gelten deren eigene Datenschutzbestimmungen.

Auf die Windows-Zwischenablage wird nur nach einer ausdrücklichen Nutzeraktion zum Kopieren des erzeugten Importtexts zugegriffen. Vom Nutzer ausgewählte Texte oder Dateien werden nur nach einem ausdrücklichen Einfügen, Auswählen oder Laden gelesen.

### World-of-Warcraft-Dateien

Die routinemäßige Ergebnisübertragung verwendet ein integritätsgeprüftes Copy/Paste-Format. Eine optionale Dateiinstallation ist standardmäßig deaktiviert und erfolgt nur nach einer ausdrücklichen Nutzeraktion sowie den fail-closed World-of-Warcraft-Prozessprüfungen. Die Anwendung verändert niemals extern die SavedVariables von World of Warcraft.

### Löschen

Die Deinstallation des Microsoft-Store-Pakets entfernt die paketierte Anwendung. Lokal erzeugte Nutzerdaten können unter `%LOCALAPPDATA%\LocalGearAdvisor` erhalten bleiben, damit eine Deinstallation oder Aktualisierung Simulationsergebnisse nicht stillschweigend zerstört. Nutzer können dieses Verzeichnis manuell löschen, wenn sie die Daten nicht mehr benötigen. Daten des World-of-Warcraft-Addons bleiben in der World-of-Warcraft-Installation, bis sie vom Nutzer entfernt werden.

### Kontakt

Datenschutzfragen können über den öffentlichen Issue-Tracker des Projekts gestellt werden:
https://github.com/Madchristian/local-gear-advisor/issues
